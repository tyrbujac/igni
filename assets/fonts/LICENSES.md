# Bundled font licenses

These TTFs are bundled with Igni so generated apps work offline. Each is
redistributed under its upstream licence. Full licence texts live in
`licenses/` alongside this file.

| File | Family name (TTF `name` table) | Licence | Upstream |
|------|--------------------------------|---------|----------|
| Roboto-Regular.ttf | Roboto | Apache-2.0 | https://fonts.google.com/specimen/Roboto |
| Roboto-Medium.ttf | Roboto | Apache-2.0 | https://fonts.google.com/specimen/Roboto |
| Pacifico-Regular.ttf | Pacifico | OFL-1.1 | https://fonts.google.com/specimen/Pacifico |
| Inter-Regular.ttf | Inter | OFL-1.1 | https://fonts.google.com/specimen/Inter |
| SourceSans3-Regular.ttf | Source Sans 3 | OFL-1.1 | https://fonts.google.com/specimen/Source+Sans+3 |
| Merriweather-Regular.ttf | Merriweather | OFL-1.1 | https://fonts.google.com/specimen/Merriweather |
| Lora-Regular.ttf | Lora | OFL-1.1 | https://fonts.google.com/specimen/Lora |
| FiraCode-Regular.ttf | Fira Code | OFL-1.1 | https://fonts.google.com/specimen/Fira+Code |

The non-Roboto files are variable fonts (single TTF containing multiple
weights / widths). The `-Regular` suffix is our convention, not part of the
TTF — the `name` tables still read as the bare family name above.
