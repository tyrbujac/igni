# Igni v0.12.2 — Micro Reference

Syntax-only. Indentation-based. Colons open blocks. Lowercase = built-in primitive, PascalCase = user-defined.

## Hello

```igni
screen Hello:
  label "Hello, World!"
```

## Screens

```igni
screen Home:
  count = 0

  layout vertical, padding: large:
    label count, style: heading
    button "Add", on tap: count = count + 1

screen Profile(user), title: "Profile", background: "bg.jpg":
  label user.name, style: heading
```

Optional props: `title:`, `background:` (colour or image). Bodies stack vertically.

## Variables

```igni
name = "Tyr"
count = 0
price = 9.99
active = true
items = []
fields = {name: "Tyr", age: 24}
weather = null
color = green
items: [Product] = []
```

Arithmetic: `+ - * /`. String concat: `"hi " + name`. Field: `obj.field`. Index: `items[0]` (null on out-of-bounds).

## Events

```igni
on tap: save()
on touch: play("click.wav")
on change: validate(email)
```

Attach to any primitive, layout, or component. `on change:` requires `bind:`.

## Layout

```igni
layout vertical, gap: medium, padding: large, align: center, background: card, rounded: true:
  label "Content"

layout horizontal, spread: true:
  label "Left"
  label "Right"

layout vertical, fill: true:
```

`vertical` | `horizontal`. `fill: true` is layout-only; siblings split space equally.

## Colours & Tokens

Colours: `brand`, `subtle`, `danger`, `green`, `red`, `blue`, `white`, `black`, `yellow`, `orange`, `purple`, `teal`. Background-only: `card`.

Sizes: `small`, `medium`, `large`. Text: `heading`, `heading.small`, `body`, `caption`.

Fonts (theme-level): `theme: text: <token>: font: <name>` overrides style-token fonts project-wide. Bundle: `pacifico`, `inter`, `source_sans`, `merriweather`, `lora`, `fira_code`. No per-label `font:`.

## Conditionals

```igni
if active:
  label "On"
else if pending:
  label "Wait"
else:
  label "Off"
```

For conditional values: assign default, then override.

## Boolean Logic

`not`, `and`, `or`. Equality: `is`, `is not`. Order: `>`, `<`, `>=`, `<=`. Special: `is empty`, `is not empty`, `is null`, `is not null`, `is in`, `is not in`, `is loading`, `is error`. No truthiness.

## Lists

```igni
items = items + [x]
items = without(items, x)
items = replace(items, old, new)
items = replace(items, t, {t with done: not t.done})
match = find(items, i => i.id is x)
done = filter(items, i => i.done)
by_name = sorted(items, i => i.name)
rev = reversed(items)
names = map(items, i => i.name)
n = length(items)
qty = count(items, x)

each item in items:
  label item.name
```

Lambdas: single-expression, list builtins only. `{BASE with KEY: VALUE, ...}` builds a new object from BASE plus overrides; BASE is a variable or dot-access chain.

## Functions

```igni
greet(name):
  return "hi " + name
```

Inside screens/components. Close over state.

## Components

```igni
component Avatar(url, size):
  image url, size: size, round: true

component Card(title):
  layout vertical, padding: medium, background: card:
    label title, style: heading.small
    body

component Stepper(value):
  layout horizontal:
    button "-", on tap: emit decrement
    label value
    button "+", on tap: emit increment
```

Invoke: `Avatar user.avatar, size: 80` (no parens). Wrapper: `body` renders one widget; caller wraps multiples in `layout`.

`emit <name>` inside event handler → parent attaches `on <name>:`. Data: `emit selected item` → `on selected: handle(item)`. Reserved: `tap`, `change`, `touch`. Standalone `emit` is a parse error.

## Async

```igni
user = fetch("/api/user")

if user is loading:
  spinner
else if user is error:
  label "Failed"
else:
  label user.name
```

Mutations: `fetch(url, method: "POST", body: {k: v})`.

Device location: `here = locate()`. Same async shape as `fetch`. Has `.latitude` / `.longitude` (decimal floats). One-shot; first call prompts for permission; denial → `is error`.

## Rules

- Max nesting depth 4 (`layout`/`screen`/`component`; conditionals/loops don't count; components reset).
- Reactivity: screens re-evaluate when any referenced variable is reassigned.
- List elements not mutable in place — reassign.
- Primitives only in screen/component bodies, never in functions.
- Screen/component args are immutable.
- No cross-screen function calls — use `shared:`.
- One way to do everything. No aliases.
